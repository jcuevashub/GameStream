# GameStream

**GameStream** is a real-time game streaming app that allows users to stream their favorite games directly from their devices. Developed using **Swift** and **SwiftUI**, this app provides a smooth, high-performance experience with a modern and intuitive user interface.

## Features

- **User-Friendly Interface**: Built with SwiftUI, offering a clean and responsive design.
- **Easy Navigation**: Seamless transitions between different game categories and streaming options.
- **Game Library**: Browse a diverse library of games available for streaming.

## Tech Stack

- **Swift**: Core programming language for iOS development.
- **SwiftUI**: Framework used for building user interfaces in a declarative style.
- **Combine**: Used for reactive programming and managing the app’s data flow.
- **CoreData**: Persistent storage for saving user preferences and streamed games.
- **AVFoundation**: For handling the video and audio streaming components.
